# Cluster selection

`example-management` is the complete selected management Application root. `example-sno` is a selected **storage fragment**, not a complete standalone cluster/bootstrap root. It provides the SNO storage Application; compose it into a reviewed root with the required core configuration before using it as a bootstrap source. Their generated Applications are owned by secure-ai-datacenter canonical inputs, not this inventory document. Read `metadata.yaml` in the corresponding compute output for release/delivery facts. Hosted API registration and secret material are private prerequisites.

Older site-specific cluster overlays are preserved in historical main Git history and are not selected by this candidate. No inventory entry proves an installed cluster.
