# Select an operator

An operator needs an available catalog/package/channel, namespace and OperatorGroup where required, a Subscription with the selected InstallPlan policy, and its actual operand configuration. Adding an Application alone does not make the catalog or controller available. Preserve Manual approval when selected. Follow a maintained operator Application rather than inheriting an obsolete fixed catalog or version.

[Architecture navigation](../ARCHITECTURE.md) identifies the real source/destination chain. [AGENTS execution](../../agents/operations.md) owns exact builds, status checks and secret-workflow invocation; do not duplicate those commands here.
