# Add an application

Choose a reusable base or chart, supply explicit site values and select an Application in the intended root. The Application names the source/ref/path and destination API/namespace. Composed site changes belong in Datacenter; reusable behavior belongs here. Build the parent root and selected child separately before delivery. After reconciliation inspect sync, health and workload readiness.

[Architecture navigation](../ARCHITECTURE.md) identifies the real source/destination chain. [AGENTS execution](../../agents/operations.md) owns exact builds, status checks and secret-workflow invocation; do not duplicate those commands here.
